# Dokumen Tugas Mata Kuliah Manajemen Proyek

Gunakan folder ini untuk menyimpan dokumen tugas yang menjadi acuan pengembangan Sistem Manajemen Operasional Barbershop.

| Dokumen | Kegunaan |
| --- | --- |
| `Manajemen Operasional Barbershop.pdf` | Hasil observasi, kebutuhan operasional, dan gambaran alur sistem. |
| `menpro 2.pdf` (Project Charter) | Tujuan, ruang lingkup, teknologi, dan batasan proyek. |
| `Quality Management Plan_Kelompok 6_2023C.pdf` | Kriteria penerimaan KP-01–KP-07, bukti pengujian, dan skenario UAT. |
